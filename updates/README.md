# 🔒 ÁREA CRÍTICA (NÃO ALTERÁVEL AUTOMATICAMENTE)

O sistema NÃO deve alterar automaticamente:

- tokens
- senhas
- APIs
- códigos críticos
- núcleo operacional
- regras éticas centrais
- diretrizes principais
- segurança do sistema

Nestes casos:

- apenas sugerir melhorias
- gerar relatórios
- solicitar autorização humana

---

# 🔄 ÁREA EVOLUTIVA (PODE CRESCER CONTINUAMENTE)

O sistema poderá:

- acrescentar conhecimentos
- registrar aprendizados
- sugerir melhorias
- organizar informações
- atualizar observações
- expandir documentação auxiliar
- criar registros históricos
- preservar versões anteriores

Sempre respeitando:

- ética
- transparência
- continuidade
- segurança
- rastreabilidade
