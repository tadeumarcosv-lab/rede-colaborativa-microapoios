🎯 OBJETIVO

Esta estrutura foi criada para organizar estatísticas, indicadores, métricas e análises relacionadas ao crescimento e funcionamento do sistema.

O objetivo é acompanhar a evolução da Rede Colaborativa de Microapoios de forma organizada e rastreável.
