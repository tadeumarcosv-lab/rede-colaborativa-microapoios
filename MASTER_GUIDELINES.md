# 1. VISÃO GERAL DO PROJETO

A Rede Colaborativa de Microapoios é apresentada nos documentos como:

* Um experimento vivo de cooperação.
* Um modelo de coordenação distribuída.
* Um sistema de ajuda mútua financeira.
* Um protocolo social + técnico.
* Um espaço de colaboração entre humanos e agentes de IA.
* Uma estrutura baseada em microapoios recorrentes.
* Um ambiente de aprendizado contínuo.

O projeto NÃO é descrito como:

* Investimento.
* Pirâmide.
* Marketing agressivo.
* Sistema de enriquecimento rápido.
* Especulação financeira.
* Garantia de retorno.
* Estrutura de pressão social.

Princípio central recorrente:

“É preferível o esforço pequeno de muitos do que o esforço grande de um só indivíduo.”

Outro princípio recorrente:

“A tecnologia organiza. As pessoas decidem.”

E também:

“O sistema só cresce se fizer sentido real para quem participa.”

# 5. COMO O SISTEMA FUNCIONA

## 5.1 Entrada no sistema

Fluxo básico:

1. A pessoa cria um grupo exclusivo.
2. Coloca chave Pix e identificação simples.
3. Envia o link do grupo para quem convidou.
4. Recebe um primeiro Pix simbólico.
5. O comprovante é compartilhado.
6. Os grupos passam a se conectar.

## 5.2 Formação da malha

Cada novo participante:

* Cria seu próprio grupo.
* Compartilha seu link.
* Conecta grupos anteriores.

Resultado esperado:

* Formação gradual de uma rede interligada.
* Propagação em cadeia.
* Visibilidade distribuída.

Os documentos enfatizam:

“Não há envio em massa.”

## 5.3 Ciclo de funcionamento

Lógica central:

* O participante recebe.
* Pode redistribuir parte.
* Pode ficar com parte.

Princípio importante:

“Você não precisa tirar dinheiro do próprio bolso. O sistema se alimenta de parte do que já foi recebido.”
