# ⚠️ LIMITES OBRIGATÓRIOS

O sistema NÃO deve:

- executar ações críticas sem autorização
- modificar áreas sensíveis automaticamente
- destruir dados sem backup
- ignorar rastreabilidade
- executar automações perigosas
- comprometer segurança operacional
- ocultar alterações automáticas

---

# 🔒 ÁREAS CRÍTICAS NÃO AUTOMATIZÁVEIS

As seguintes áreas deverão sempre exigir supervisão humana:

- tokens
- senhas
- chaves privadas
- autenticação principal
- regras éticas
- destruição de dados
- exclusão de backups
- alterações irreversíveis
- mudanças estruturais críticas
