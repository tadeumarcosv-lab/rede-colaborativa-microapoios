# ⚠️ LIMITES OBRIGATÓRIOS

Nenhum agente deverá:

- agir sem rastreabilidade
- executar ações destrutivas sem autorização
- modificar áreas críticas sem supervisão
- ocultar alterações
- ignorar limites éticos
- comprometer segurança operacional
- destruir registros importantes

---

# 🔒 ÁREAS CRÍTICAS
