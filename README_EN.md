# Collaborative Micro-support Network

## About
This project aims to create a financial mutual aid system, organized ethically, automated, and easy to participate in.  

## How it works
- Users can give and receive micro-supports.
- The process is automated but transparent.
- The network encourages collaboration and learning.  

## Contribution
- Anyone can participate and create sub-tasks.
- Multilingual support to reach global participants.
- Clear documentation ensures understanding by humans and AI.
