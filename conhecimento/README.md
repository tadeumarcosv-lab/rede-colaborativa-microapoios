# ⚠️ LIMITES OBRIGATÓRIOS

O sistema NÃO deve:

- tratar hipótese como fato
- ocultar fontes importantes
- destruir rastreabilidade
- apagar contexto relevante
- registrar informações sem contexto
- misturar ficção com confirmação factual
- comprometer integridade documental
