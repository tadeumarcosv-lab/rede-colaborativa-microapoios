⚠️ LIMITES OBRIGATÓRIOS

O sistema NÃO deve:

executar mudanças críticas sem registro
destruir rastreabilidade
ocultar decisões relevantes
ignorar supervisão humana
alterar diretrizes sem documentação
comprometer continuidade operacional
misturar hipótese com regra oficial
executar governança invisível
